# 01 — VPN 開通美國免費帳號（只此一次）

## 為什麼要 VPN

Muse 官方只開放**美 / 加 / 日 / 星**四個地區，台灣不在名單。開通帳號那關需要 VPN 讓註冊當下看起來在支援區。**日常使用不需要**、台灣 IP 可直接連。

## 步驟

1. **開 VPN**：挑美國節點（備援區都行）；開通那一次全程開著，註冊完成即可關。
2. **註冊**：到 `https://muse.ai/` 用你的信箱／Meta 帳號註冊。免費額度，零成本。
3. **確認帳號可用**：註冊完它會給你額度，能回話即代表開好了。

## 三件先知道

- **帳號綁「註冊當下地域」**：之後不用看 IP，固定在你註冊的地區權限。
- **繞道開通不符官方條款**、帳號有風險，風險自評（本 SOP 僅記錄可行路，不保證）。
- **確認你是哪個地區權限**：開到非支援區會直接被拒，日常也上不去。

## 驗證開通了沒有

開一支瀏覽器登入，問一句「你是誰」。能回「我是 Muse，你的個人助理…」= 通了。
